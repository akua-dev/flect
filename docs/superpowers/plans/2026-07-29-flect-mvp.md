# Flect MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a polished local Flect launcher that discovers authenticated
models through Pi, creates tool-free Pi sessions, streams responses, and
retains a protected safe-mode surface.

**Architecture:** A React/Vite browser shell talks to a loopback-only Bun
service through shared Zod contracts. The service embeds Pi with
`ModelRuntime` and `createAgentSession`; Pi owns credentials and provider
resolution. Customizable interface state is a validated document, while the
built-in launcher and safe mode remain outside that document.

**Tech Stack:** Bun 1.4.x, TypeScript 7.0.2, React 19.2.8, Vite 8.1.5,
`@earendil-works/pi-coding-agent` 0.82.1, Zod 4.4.3, Vitest 4.1.10, Testing
Library 16.3.2, Playwright 1.62.0, and Biome 2.5.6.

## Global Constraints

- Bind the local runtime to `127.0.0.1:3210`; never bind to all interfaces.
- Credentials remain in Pi's supported stores and never enter frontend state,
  API responses, fixtures, screenshots, or logs.
- Initial Pi sessions use `noTools: "all"` and in-memory session storage.
- The browser never calls model providers directly.
- Invalid customized interface state fails closed to the built-in launcher.
- `?safe=1` bypasses customized interface state and remains available without
  extensions.
- Do not execute generated JavaScript or add a second credential store.
- Preserve the current untracked visual assets until Robin explicitly chooses
  replacements.

# Flect v0.1.1 Trust-Boundary Hardening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship an immutable v0.1.1 patch that preserves startup recovery when storage is unavailable and rejects over-deep interface documents before recursive decoding.

**Architecture:** Keep ordinary kernel transitions transactional, but contain the startup-only reconciliation write failure after constructing the in-memory preview. Add one iterative raw-tree preflight to `validateInterfaceDocument`, and route journal, HTTP, and native shape inputs through it before recursive Effect schemas.

**Tech Stack:** Bun, TypeScript, Effect 4, React, Vitest with `@effect/vitest`, Effect HTTP/RPC, Playwright, Tauri 2, Rust.

## Global Constraints

- Effect 4 remains the application, error, resource, and UI-shaping kernel.
- Pi remains private behind loopback HTTP or the packaged stdio sidecar.
- The QuickJS sandbox accepts inert intents only.
- The protected launcher and `/?safe=1` recovery route must remain available.
- No existing `v0.1.0` tag or release asset may be rewritten.
- No arbitrary UI import, capsule, product API, notarization, or cross-platform claim is added.

- [ ] **Step 3: Implement the iterative preflight**

Add an internal non-recursive walker:

```ts
const preflightTree = (input: unknown) => {
  const root = readUnknownProperty(input, "root");
  const pending: Array<readonly [unknown, number]> = [[root, 1]];
  const seen = new Set<object>();
  let count = 0;

  while (pending.length > 0) {
    const [node, depth] = pending.pop()!;
    count += 1;
    if (depth > 10 || count > 100 || !isRecord(node) || seen.has(node)) {
      return false;
    }
    seen.add(node);
    if (node.type === "stack" && Array.isArray(node.children)) {
      if (node.children.length > 30) return false;
      for (const child of node.children) pending.push([child, depth + 1]);
    }
  }
  return true;
};
```

Run it before `decodeCurrentDocument`. In revision validators, extract each raw
revision document and call `validateInterfaceDocument` before decoding the
embedding revision or snapshot schema.
